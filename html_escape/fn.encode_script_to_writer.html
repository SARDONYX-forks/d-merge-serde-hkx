Expand description

Write text used in the <script> element to a writer.

The following substring is escaped:

  • </script> => <\/script>
  • <!-- => <\!--

Use this encoder for <script> elements in the HTML namespace of a text/html document. </script at the end of the text is also escaped, because the text after it can end the element. Pass the whole element text in one call; separate calls do not share parsing state. This scans text without parsing JavaScript and may change its meaning. Existing escapes are kept, so encoding and decoding may not return the original text. This is not a JSON encoder; the \! escape is not valid JSON. For JSON, first serialize the data as JSON, then replace each literal < with \u003C. Use a quoted text encoder when inserting raw text into a JavaScript string.
