1/*!
2# HTML Escape
3
4This library is for encoding/escaping special characters in HTML and decoding/unescaping HTML entities as well.
5
6## Usage
7
8### Encoding
9
10This crate provides some `encode_*` functions to encode HTML text in different situations.
11
12Escaping is context-sensitive.
13Use `encode_text` for text, quoted attribute encoders for quoted attributes, `encode_unquoted_attribute` for unquoted attributes, and script or style encoders for raw-text elements.
14`encode_safe` is not a context-independent sanitizer.
15
16For example, to put a text between a start tag `<foo>` and an end tag `</foo>`, use the `encode_text` function to escape every `&`, `<`, and `>` in the text.
17
18```rust
19assert_eq!("a &gt; b &amp;&amp; a &lt; c", html_escape::encode_text("a > b && a < c"));
20```
21
22The script and style encoders are for `<script>` and `<style>` in the HTML namespace of a `text/html` document.
23Do not use them in inline SVG, where the parser decodes character references inside `<script>` and `<style>`, so `&apos;` can become a quote that ends a string.
24
25The script and style `*_quoted_text` functions take raw string content and do not add outer quotes.
26They escape every backslash, including those in existing escape sequences, and also C0 control characters and every `<`.
27Script variants also escape U+2028 and U+2029.
28Style variants replace NUL with U+FFFD, so an input containing NUL cannot round-trip without a change.
29Use these functions for single-quoted or double-quoted string content inside `<script>` or `<style>`.
30
31Since 0.3.0, the `*_quoted_text` encoders escape every input backslash.
32Pass the original text and remove manual string escaping at the call site; for example, pass `C:\temp\file` instead of `C:\\temp\\file`.
33Their decoders also decode escaped backslashes and hex escapes.
34They still recognize legacy tag and comment escapes, but some decoding results differ from 0.2.
35
36```rust
37let text = r"C:\temp\file";
38assert_eq!(r"C:\\temp\\file", html_escape::encode_script_single_quoted_text(text));
39assert_eq!(text, html_escape::decode_script_single_quoted_text(r"C:\\temp\\file"));
40assert_eq!("\n", html_escape::decode_script_single_quoted_text(r"\x0A"));
41assert_eq!(r"\x0A", html_escape::decode_script_single_quoted_text(r"\\x0A"));
42```
43
44`encode_script` and `encode_style` scan the whole element text without parsing JavaScript or CSS.
45They insert backslashes before tag and comment sequences, so check that the result is valid in the target language.
46They keep existing escapes, so encoding and decoding may not return the original text.
47For example, `<\/script>` stays the same during script encoding, but script decoding changes it to `</script>`.
48`encode_script` is not a JSON encoder; its `\!` escape for `<!--` is not valid JSON.
49To put JSON inside `<script type="application/json">`, serialize the data as JSON first, then replace each literal `<` with `\u003C` in the JSON text.
50
51```rust
52let json = r#"{"text":"<!--</script>"}"#;
53let escaped_json = json.replace('<', r"\u003C");
54let html = format!(r#"<script type="application/json">{}</script>"#, escaped_json);
55assert_eq!(r#"<script type="application/json">{"text":"\u003C!--\u003C/script>"}</script>"#, html);
56```
57
58The functions suffixed with `_to_writer`, `_to_vec` or `_to_string` are useful to generate HTML.
59The `_to_string` and `_to_vec` functions append to the output and return only the slice written by the current call.
60The `_to_writer` functions accept writers including `&mut dyn std::io::Write`.
61Pass the whole element source in one call to `encode_script` or `encode_style`, including their output variants; separate calls do not share tag-matching state.
62Quoted string encoders can be appended in chunks because they escape every `<`.
63For an empty attribute value, use a quoted attribute; the unquoted attribute encoder does not add quotes.
64
65```rust
66let mut html = String::from("<input value=");
67assert_eq!("Hello&#x20;world&#x21;", html_escape::encode_unquoted_attribute_to_string("Hello world!", &mut html));
68html.push_str(" placeholder=\"");
69assert_eq!("The default value is &quot;Hello world!&quot;.", html_escape::encode_double_quoted_attribute_to_string("The default value is \"Hello world!\".", &mut html));
70html.push_str("\"/><script>alert('");
71assert_eq!(r"\x3Cscript>\'s end tag is \x3C/script>", html_escape::encode_script_single_quoted_text_to_string("<script>'s end tag is </script>", &mut html));
72html.push_str("');</script>");
73
74assert_eq!(r#"<input value=Hello&#x20;world&#x21; placeholder="The default value is &quot;Hello world!&quot;."/><script>alert('\x3Cscript>\'s end tag is \x3C/script>');</script>"#, html);
75```
76
77### Decoding
78
79Decoding accepts exact named and numeric character references ending with `;`.
80It does not apply legacy semicolonless references or C1 control replacements used by browser tokenizers.
81
82```rust
83assert_eq!("Hello world!", html_escape::decode_html_entities("Hello&#x20;world&#x21;"));
84```
85
86```rust
87assert_eq!("alert('<script></script>');", html_escape::decode_script(r"alert('<script><\/script>');"));
88```
